WHAT THIS IS
────────────
A complete internal dashboard for a real estate company, written in
plain PHP with MySQL. No Laravel, no Composer, no npm, no Vite.
Just PHP files + one CSS file + one JS file. Drop into Wamp/XAMPP.

FEATURES
────────
- Login + brute-force lockout + forced first-login password reset
- 4 roles: Admin, Accounts, Management, Site Manager
- Projects (5 types: residential, commercial, plot, villa, mixed)
- Units — add / bulk create with prefix pattern / sell / release / cancel
- Payments — accrued / received / receivable
- Expenses — 2-stage approval (Accounts → Management)
              with receipt upload and rejection reasons
- Stock book (opening + inward + outward + auto-computed closing)
- Users — invite (SMTP or on-screen temp password) / reset / deactivate
- Settings — company name, currency, expense threshold, logo upload
- Audit log — every action recorded with actor + timestamp
- Dashboard with KPIs and monthly revenue bar chart (CSS bars, no JS lib)

WHAT YOU NEED
─────────────
- PHP 8.0+ (or 7.4 will also work)
- MySQL 5.7+ or MariaDB 10.3+
- Any web server: Wamp / XAMPP / Laragon / built-in `php -S`

That's it. No composer, no npm, no node.

SETUP (Windows / Wamp — takes 5 minutes)
────────────────────────────────────────
1. Extract this zip into your Wamp www folder:
       C:\wamp64\www\realestate\
   (the folder should have `config.php`, `install.php`, `login.php`, etc.)

2. Open phpMyAdmin:  http://localhost/phpmyadmin
   Click "New" → name it exactly:  realestate
   Collation:  utf8mb4_unicode_ci    → Create

3. Open  config.php  in Notepad.
   Verify these lines match your Wamp setup:

       'db_host'  => '127.0.0.1',
       'db_name'  => 'realestate',
       'db_user'  => 'root',
       'db_pass'  => '',           <-- blank for default Wamp
       'base_url' => 'http://localhost/realestate',

4. Open in browser:  http://localhost/realestate/install.php
   Click "Install now".
   You'll get a screen showing:

       Email    : sales@agrocorp.co.in   (or the smtp_from you set)
       Password : xxxxxxxxxxxxxx         <-- COPY THIS NOW

5. IMPORTANT: after install, delete or rename install.php so nobody
   can re-run it.

6. Open:  http://localhost/realestate/login.php
   Sign in with the admin creds from step 4.
   You'll be forced to set a new password on first login.


SETUP (macOS / Linux — using the built-in PHP server)
─────────────────────────────────────────────────────
    cd realestate
    # edit config.php, then:
    php -S localhost:8000

    Open http://localhost:8000/install.php
    Then http://localhost:8000/login.php


DATABASE
────────
All tables are created by install.php. Schema highlights:
  users, projects, project_user (pivot), units, payments,
  revenue_targets, expenses, stock_items, stock_movements,
  notifications, audit_logs, login_attempts, settings

To reset everything: drop and re-create the database, re-run install.php.


SMTP INVITE EMAILS (optional)
─────────────────────────────
If you want the user-invite emails to actually send, edit  config.php
and fill in the SMTP block:

    'smtp_host' => 'smtp.gmail.com',
    'smtp_port' => 587,
    'smtp_user' => 'sales@yourdomain.com',
    'smtp_pass' => 'YOUR_GOOGLE_APP_PASSWORD',
    'smtp_from' => 'sales@yourdomain.com',
    'smtp_name' => 'Your Company Internal',

If SMTP is left blank, invites still work — the temp password is
shown on-screen after creating each user, so you can share it manually
via WhatsApp or another channel.

Note: current implementation uses PHP's mail(). On Wamp this needs
sendmail configured in php.ini. For production, use a proper SMTP
library (PHPMailer). Ping me if you want me to add that.


DEPLOYING TO HOSTINGER / cPANEL
───────────────────────────────
1. Zip the whole folder.
2. Upload to  public_html/  via cPanel File Manager, extract there.
3. In cPanel → MySQL Databases → create db + user, note credentials.
4. Edit  config.php  with the production DB creds and:
       'base_url' => 'https://your-domain.com',
5. Visit  https://your-domain.com/install.php  → run installer.
6. DELETE  install.php  from the server.


TROUBLESHOOTING
───────────────
"could not find driver"
   → PHP pdo_mysql extension missing. In Wamp click the icon → PHP →
     PHP extensions → tick php_pdo_mysql, restart Wamp.

"SQLSTATE[HY000] [1049] Unknown database 'realestate'"
   → You skipped step 2. Create the database first.

"SQLSTATE[HY000] [1045] Access denied for user 'root'@'localhost'"
   → Wrong password in config.php. Wamp default is blank.

Cannot upload receipts / images
   → chmod 775 uploads/  (Windows: right-click → Properties → Security →
     give the user "Modify" permission)

Login page is blank / white screen
   → Turn on error display. Add to the top of config.php:
        ini_set('display_errors', 1);
        error_reporting(E_ALL);
     Refresh and read the error message.
