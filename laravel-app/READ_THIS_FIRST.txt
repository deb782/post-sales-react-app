FASTEST SETUP (Windows)
───────────────────────
1. Extract this zip to  C:\wamp64\www\laravel-app
2. Create the MySQL database:
     Open http://localhost/phpmyadmin
     Click "New" → name it  realestate_dashboard  → utf8mb4_unicode_ci → Create
3. Open PowerShell in the laravel-app folder and run:
     .\setup.ps1
4. When prompted, edit .env in Notepad:
     DB_PASSWORD=          (blank for Wamp default)
     MAIL_PASSWORD=        (blank if not sending real emails yet)
5. Continue the script.  At the end you'll see:

     ===================================
      Admin seeded
     ===================================
      Email    : sales@agrocorp.co.in
      Password : xxxxxxxxxxxxxx     ← COPY THIS
     ===================================

6. Start the server:
     php artisan serve
7. Open  http://localhost:8000/login  and sign in.

TROUBLESHOOTING
───────────────
"No application encryption key" → run:  php artisan key:generate
"Please provide a valid cache path" → run:  php artisan view:clear
Any other 500 → open  storage\logs\laravel.log , the LAST error is the cause.
